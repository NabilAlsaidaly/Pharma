# Educational Content security and editorial safeguards

Existing private Owner prefix/guard/active status/current credential version/session idle+absolute semantics/CSRF/no-store remain authoritative. Every Article/Category command revalidates persisted Owner under S lock and serializes mutations on a dedicated coordination row. No accepted Owner ID, table/column name or disk path from browser input. UUID selectors are identifiers only, never authorization. Ten protected routes share current RequireOwner; guest/Customer/disabled/restricted/revoked/idle tests cover all.

Strict command/nested allowlists and canonical types: safe decimal-string versions, UUIDv4/v7 operations, integer orders, boolean flags, bounded UTF-8 metadata and structured blocks. Body permits fixed safe text/heading/list/image types and strong/em/HTTPS presentation only. No HTML storage, contenteditable DOM parsing, arbitrary CSS/props, SVG, iframe, JS, Markdown parser or dangerous innerHTML. Paste is plain textarea text; previews construct fixed DOM tags/textContent. Server preview escapes text/URLs and outputs fixed tags without indentation injecting run text. APIs return data, not executable HTML.

href/source URLs are absolute HTTPS, bounded2048, no credentials/custom port/control/backslash/protocol-relative/javascript/data. No fetching, link previews, DNS/source/clinical verification or guessed frontend paths. External render links use safe attributes; accepting syntax does not certify credibility. Schema1 unknown fields/types/versions reject422; no silent downgrade or unknown extension execution.

Private local raster storage with server UUID names: actual extension/MIME/content/decode checks, reject executable polyglots/SVG, input5MiB,dimension4096,pixels4194304,GD PNG output8MiB. Flatten animation/strip metadata. Optional cover+5inline, alt mandatory; no remote image or Catalog copying. Generated immutable path `education/{id}.png`; private Owner previews verify retained membership. Public bytes require current unarchived Article publication and exact revision membership; known draft/replaced/unpublished/archive assets404. No filesystem probing per summary image; existence checked on publish and binary request. Compensate fresh file after real SQL failure; retained old files/crash orphans remain operational concerns.

Public summaries omit body, sources, internal images, drafts/audit/Owner credentials/paths. Detail uses an explicit safe projection and current Catalog visibility, no hidden metadata fallback. All public metadata/media/errors no-store/private and X-Request-ID; request-body/unknown-filter/search/page caps. Owner writes60attempts/min, normal256KiB/media10MiB, source5MiB; failed/retried attempts count. Proxy/PHP limits may be stricter and must be checked operationally. No new public write endpoint or relaxed CORS/auth.

Public unexpected exception logs contain only exception class+request ID under `education_http_failed`; private Owner uses existing sanitized reporter. Generic audit records field names, no Article body/raw HTTP/Customer contact. Full content remains private immutable revision history unless explicitly published. No sensitive old-input flashing in validation response. Constraint conflicts/stale409, malformed422, excessive413/429, missing schema503, nonexistent/unpublished404.

Editorial health controls record Owner's explicit publication review; health_related requires a source and additional acknowledgment. No claim of clinical truth, professional qualification, doctor signature, diagnosis, dosage or scientific approval; no invented citations or public medical disclaimer. Product links do not establish suitability or trigger purchases/messages. Software tests prove these controls, not medical accuracy. Full WCAG, penetration testing, production capacity, retention/legal policy and multi-node infrastructure are separately assessed.
