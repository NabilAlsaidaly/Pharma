# Catalog administration security

Every endpoint is under the fail-closed private prefix, existing exact active Owner guard/RequireOwner, idle/version revocation, production HTTPS/session checks, no-store/deny-frame/nosniff/no-referrer. No public writes, Customer admission, registration/default credentials, account lifecycle or staff RBAC. Menu visibility is never authorization. OwnerCatalogRequest repeats exact active Owner authorization before explicit allowlisted validation; CatalogChange requires a persisted active Owner context. Business services remain private in-process, not public APIs.

All mutations require Laravel CSRF. Existing identity/Customer body limits remain unchanged through delegating middleware; only named Owner Catalog routes allow8MiB. PHP/proxy post_max_size/upload_max_filesize must support documented limits at rollout. Form errors use sanitized Arabic HTML422; stale version/ownership/unique race409; no SQL/bindings/trace or unsafe user-controlled return URL. Text is Blade-escaped, not rich HTML. Prices stay strict decimal strings; dangerous UUID/timestamp/owner/parent reassignment fields rejected. Filesystem paths never accepted as editable attributes.

Raster uploads inspect dimensions/MIME/extension/content and GD decode before generated PNG re-encode. Max5MiB,4,194,304pixels,4096 per dimension,20 current Product images. Reject SVG/HTML/PHP/double executable names/traversal/corrupt/unsupported/mismatched formats; no remote URL import. Actual MIME is inspected, not trusted from client. Re-encoding removes metadata/animation/executable tails; explicit PHP/script signatures rejected. Immutable generated names prevent overwrite; retain old files/logos and compensate only newly generated path on SQL failure. Missing file blocks restore. GD absent yields503, no fabricated successful upload. Production public serving must never execute files from upload storage. Test fake storage and guarded browser-only media root are isolated.

Bulk resources/actions are fixed lists, IDs validated/distinct, filters whitelisted, cap100. One server-session confirmation holds exact IDs/versions/action and10minute expiry; explicit consent required. Execution rechecks matching set/current archive state/version under deterministic locks, atomically saves via Eloquent/audits. Missing/stale/changed/oversized sets roll back entirely, no silent skips/false success. Replays fail after success. Browser clear/page/history reset scope and IDs; selection alone never executes. Business audit has no mutation/delete endpoint, no credentials/PII; logs only existing safe correlation/exception metadata.

Residual limits: malicious trusted DBA/raw SQL can bypass application invariants/audit; filesystem/SQL crash atomicity is not guaranteed, possible orphan retained files require separately approved operational reconciliation. Native zoom/full screen-reader/production proxy/session/log/storage deployment and capacity verification are separate evidence. No stock, payment, confirmed Order or notification flow.
