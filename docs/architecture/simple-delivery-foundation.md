# Simple delivery foundation

[ADR027](../adr/ADR-027-simple-delivery-foundation.md) implements the approved [gate](../reports/phase-06h-simple-delivery-design-gate.md). The operation remains manual. Customers enter their existing Checkout contact or Gift recipient; the Owner uses those original private details, not a duplicate address form.

Settings retains Zone configuration/identity/fees/revisions/command history. Its existing public flag now permits explicit informational publish/unpublish of Zones. PublishedDeliveryZones selects exact current published revision values, never latest drafts, and projects only safe named fields inside a single repeatable-read transaction for list+count. Conditions remain private. Archive clears the pointer, restore remains unpublished. No existing Zone automatically publishes.

Delivery contains one worker command, one directory/history reader, two HTTP controllers and one bounded transport middleware; no empty Action/DTO/Repository layers. Worker commands validate fixed fields, current persisted Owner role/status/credential, exact expected version, durable operation fingerprint and target. Owner-X then replay lookup then Worker-X, atomic update+change insert, retry up to3 transient database conflicts. Same-key identical committed replay wins before current target version after current authorization; changed payload409. New operations may create contacts sharing a phone/name. A stored operation is not permission to bypass later Owner revocation.

The private Delivery destination links existing Zone CRUD and offers a25-row worker directory/create/edit/enable/disable and bounded change journal. No assignment or communication action. Sources: [ManageDeliveryWorker](../../app/Domains/Delivery/Application/ManageDeliveryWorker.php), [reader](../../app/Domains/Delivery/Infrastructure/DeliveryWorkers.php), [Zone projection](../../app/Domains/Settings/Infrastructure/PublishedDeliveryZones.php).

All existing Orders/Gifts commercial commands remain unchanged. The public Zone list does not certify geographic coverage; governorate-only and governorate+city entries have no overlap priority, inheritance or fallback. No configured zone is required to submit a valid preliminary request.
