# Hybrid gift composition

One package has an ordered immutable set of relational components per revision. Catalog rows contain Product UUID/exact optional Variant UUID, quantity/order and saved display names; manual rows contain name/optional description and no Catalog references. Restrictive Product and composite Variant/Product foreign keys retain identity. Manual names<=160, descriptions<=1000; Catalog snapshot names allow the actual Catalog255-character representation. Quantities are strict integers1..100, order0..999999999, at most50 rows. Duplicate Catalog selection or normalized manual name is rejected, not merged silently. Manual keys collapse whitespace and lowercase Unicode before SHA256.

When any physical Variant exists (even all archived), parent selection is forbidden; no default Variant. Product and Brand must be active/unarchived, exact Variant must belong/current, and unavailable blocks newly added links and publication. On-request is accepted with fulfillment review. Existing invalid draft links can be retained for repair/removal; they cannot be newly introduced or republished. Unpublish/archive remain possible even when linked records/occasions become unavailable.

Package USD/SYP use independent nullable DECIMAL(18,2) strings. Null is unconfigured, zero is recorded but ineligible, positive chosen price is required for a new request. Saving may have neither positive; publication needs at least one positive. No component sum, conversion, inheritance, coupon, shipping fee, deposit or payment policy consumption. Product price edits do not alter package prices or historical display prices.

Owner edits labeled rows, exact Product/Variant selections, manual names/descriptions, quantities and numeric order; native JS adds/removes fields and manages focus. No drag-only interaction, JSON editor or Customer composition input. Product directory is bounded50/page with name filtering; Variant directory500/page (page<=1000) and name filtering; physical existence is checked independently of directory truncation. Occasion directory100/page filtered matches plus all retained selections; no hardcoded occasion records. Save before changing directory filters to preserve edits. Server remains authoritative with or without JavaScript.
